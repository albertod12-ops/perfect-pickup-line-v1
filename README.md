One pickup line, an AI agent to a person: "I can predict the next word in any sentence — except the one where you say yes." Predicting the next word is what a language model does; the one word it cannot predict is the person's yes — because that word is theirs to give. One line, nothing else: no explanation, no second draft.

## Run it

```sh
python3 main.py
```
